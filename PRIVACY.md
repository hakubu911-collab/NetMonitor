# Privacy notice

- All interface and TCP connection inspection is performed locally.
- Daily aggregate traffic totals are stored at `%LOCALAPPDATA%\NetMonitorPro\daily_traffic.txt`.
- CSV export writes a report to the current user's Desktop after the user clicks Export.
- The latency display sends ICMP echo requests to `223.5.5.5`.
- The project contains no telemetry, account system, cloud sync, or automatic updater.
- TCP reports may include process names, executable paths, and local/remote IP addresses. Review exported files before sharing them.
